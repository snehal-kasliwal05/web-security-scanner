\# Web Security Scanner



A Python-based web security project focused on identifying common web security issues, especially XSS-related weaknesses.



\## Features

\- Django & Flask template scanner

\- CSP analysis

\- Cookie security checks

\- Security headers checks

\- Input validation testing

\- DOM XSS-related analysis



\## Project Structure

\- `notebooks/` - original Jupyter notebooks

\- `scanner/` - Python files for different scanning mechanisms

\- `main.py` - main file to run the project

\- `demo/` - screenshots or demo output



\## Tech Used

\- Python

\- Requests

\- BeautifulSoup

\- Web Security concepts



\## Disclaimer

This project is for educational and authorized testing purposes only.
